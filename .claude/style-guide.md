## Components

> **TODO:** Define component styles after discussion

### Buttons

**Primary Button:**
- Background: Brand color
- Text: White (#fff)
- Border: 1px solid brand color
- Border radius: 5px
- Padding: 12px 22px
- Font: Montserrat, 16px, bold

**Outline Button:**
- Background: White (#fff)
- Text: Brand color
- Border: 1px solid brand color
- Border radius: 5px
- Padding: 12px 22px
- Font: Montserrat, 16px, bold

### Links

- Color: Inherit from parent (in body text)
- Underline: None by default
- Footer links: #767676
