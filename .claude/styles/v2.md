# Style Guide v2

**Version:** 2.1
**Based on:** Modern minimal aesthetic with floating elements
**Last Updated:** January 2026

---

## Overview

v2 is a modern, minimal design system focused on clarity, breathing room, and a light, airy feel. The design prioritizes readability and a premium aesthetic.

**Design Principles:**

1. **Floating Elements** - Cards float on a clean white background with generous spacing between them
2. **Light & Airy** - Subtle greys, lighter typography weights, and ample whitespace
3. **Single Accent Color** - Vibrant cyan accent for CTAs and interactive elements
4. **Refined Typography** - Smaller, lighter body copy for a sophisticated feel
5. **Generous Rhythm** - Consistent vertical spacing creates visual calm

## Spacing System

### Base Unit

The spacing system uses an **8px base** with a focus on generous whitespace.

| Token | Value | Usage |
|-------|-------|-------|
| `xs` | 8px | Tight spacing, inline elements |
| `sm` | 12px | Small gaps |
| `md` | 16px | **Module gaps**, standard spacing |
| `lg` | 24px | Section padding, heading margins |
| `xl` | 32px | Large sections |
| `2xl` | 48px | Body padding, major sections |
| `3xl` | 64px | Hero sections |

### Module Spacing (Critical)

**Every module has 16px margin-bottom** to create consistent vertical rhythm:

```
┌─────────────────┐
│    Module A     │
└─────────────────┘
        ↕ 16px
┌─────────────────┐
│    Module B     │
└─────────────────┘
        ↕ 16px
┌─────────────────┐
│    Module C     │
└─────────────────┘
```

### Container Spacing

| Element | Padding | Notes |
|---------|---------|-------|
| Body | `48px 0` | Top/bottom breathing room |
| Card module | `36px 40px` | Generous interior |
| Small card | `28px 32px` | Two-column cards |
| Header | `24px 40px` | Lighter than content |
| Footer | `40px 40px` | Balanced |

### Component Spacing

| Element | Value | Notes |
|---------|-------|-------|
| Heading to body | `16px` | margin-bottom on headings |
| Paragraph to paragraph | `16px` | Between paragraphs |
| Body to button | `24px` | Space before CTA |
| List items | `8px` | Comfortable scanning |
| Column gutter | `16px` | Between columns |

## Design Rationale

### Why these changes?

1. **Pure white background** - Creates maximum contrast with cards, feels cleaner and more premium than off-white

2. **Lighter body text (#374151 at 300 weight)** - Reduces visual heaviness, creates a more sophisticated, editorial feel. The generous line-height (1.7) maintains readability

3. **Bright cyan accent (#91E6F7)** - Modern, energetic, and distinctive. Works well as a CTA color that draws attention without being aggressive

4. **Consistent 16px module gaps** - Creates predictable vertical rhythm. Every card/module floating with equal spacing looks intentional and clean

5. **Larger border-radius (20px)** - Softer, friendlier appearance. Pairs well with the minimal color palette

6. **Smaller typography (15px body)** - Combined with light weight, creates a refined, professional look. Not "chunky" or overly bold

7. **Unified color system** - Single accent color family (cyan) instead of green + blue creates stronger brand cohesion

## Accessibility Notes

- **Accent Cyan (#91E6F7)** on white does not meet WCAG contrast for text - use `#0891B2` or `#065663` for readable text
- Button text on `#91E6F7` uses `#065663` to ensure 4.5:1 contrast ratio
- Body text `#374151` on white provides 7.5:1 contrast ratio (AAA compliant)
- All headings use `#111827` which provides 16:1 contrast ratio
