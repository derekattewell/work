# Style Guide v2

**Version:** 2.3
**Based on:** Modern minimal aesthetic with floating card design + ITRG brand colors
**Last Updated:** January 2026

---

## Overview

v2 is a modern, minimal design system focused on clarity, breathing room, and a light, airy feel. The design features a light grey background with a white rounded container that holds all content, creating a "floating card" effect for the entire email.

**Design Principles:**

1. **Floating Container** - White rounded container floats on light grey background
2. **Light & Airy** - Off-white background, lighter typography weights, ample whitespace
3. **Brand Blue Accent** - ITRG blue (#216aa5) for primary CTAs, lighter blue (#5a9bc7) for secondary
4. **Refined Typography** - 15px body copy with light weight, full type scale (H1-H5)
5. **Symmetrical Rhythm** - Equal spacing above and below modules creates visual balance

## Spacing System

### Base Unit

The spacing system uses an **8px base** with a focus on generous whitespace.

| Token | Value | Usage |
|-------|-------|-------|
| `xs` | 8px | Tight spacing, inline elements |
| `sm` | 12px | Small gaps, header bottom padding |
| `md` | 16px | Heading margins |
| `lg` | 24px | Section padding, heading margins |
| `xl` | 32px | Card button spacers, container radius |
| `2xl` | 48px | Content side padding |

### Module Spacing (Critical)

**Every module has symmetrical 10px padding top AND bottom** creating 20px gaps between modules:

```
┌─────────────────┐
│    Module A     │
│                 │  ← 10px bottom padding
└─────────────────┘
        ↕ 20px total gap
┌─────────────────┐
│                 │  ← 10px top padding
│    Module B     │
│                 │  ← 10px bottom padding
└─────────────────┘
        ↕ 20px total gap
┌─────────────────┐
│                 │  ← 10px top padding
│    Module C     │
└─────────────────┘
```

### Container & Content Spacing

| Element | Value | Notes |
|---------|-------|-------|
| Body padding | `32px 0` | Top/bottom outside container |
| Content side padding | `48px` | Typography modules |
| Card side margins | `32px` | Space between card and container edge |
| Card interior padding | `36px 40px` | Inside cards |
| Small card padding | `28px 32px` | Two-column cards |
| Header padding | `28px 48px 12px 48px` | More top, less bottom |
| Footer padding | `40px 48px` | Balanced |

## Email-Safe Spacing Techniques

### For spacing between elements inside a module:

**DO use:** Spacer rows with explicit height
```html
<tr>
  <td style="height:32px;line-height:32px;font-size:0">&nbsp;</td>
</tr>
```

**DON'T use:** `padding-top` on tables (doesn't work in email clients)
```html
<!-- This won't work! -->
<table style="padding-top:32px">
```
