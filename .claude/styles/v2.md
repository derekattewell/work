# Style Guide v2

**Version:** 2.0
**Based on:** v1 + Wealthsimple floating elements aesthetic
**Last Updated:** January 2026

---

## Overview

v2 introduces a modern, airy aesthetic inspired by Wealthsimple's email design while maintaining SR/ITRG brand identity. The key changes are:

1. **Floating Elements Effect** - Email body and container share the same background color, making content sections appear to float
2. **Cleaner Typography** - Larger body text with tighter letter-spacing
3. **Generous Spacing** - More breathing room between sections
4. **Pill-Shaped Buttons** - Fully rounded buttons for a softer, modern look

## Spacing System

### Base Unit

The spacing system is based on multiples of **8px** with emphasis on generous whitespace.

### Container Spacing (Updated)

| Element | Padding | Notes |
|---------|---------|-------|
| Body | `48px 0` | **Increased** - more breathing room |
| Standard module | `32px 48px` | **Increased** - more internal padding |
| Card module | `40px 48px` | Cards have extra top/bottom |
| Full-width image | `0` | Edge-to-edge |
| Header | `32px 48px` | Consistent with modules |
| Footer top | `48px 48px` | Generous footer spacing |
| Footer bottom | `0 48px 48px` | Consistent padding |

### Section Vertical Spacing (Updated)

| Element | Spacing | Notes |
|---------|---------|-------|
| Between floating cards | `24px` | Gap between cards |
| Between sections (major) | `48px` | **Increased** - breathing room |
| Between sections (minor) | `32px` | Standard module gap |
| Header to first content | `32px` | Clean start |
| Last content to footer | `48px` | Clean end |

### Inner Spacing

| Element | Padding | Notes |
|---------|---------|-------|
| Card inner padding | `40px 48px` | Generous card interior |
| Small card padding | `32px` | Two-column cards |
| Column gutter | `24px` | Space between columns |

### Component Spacing

| Element | Padding/Margin | Notes |
|---------|----------------|-------|
| Button | `14px 28px` | **Increased** - more substantial |
| Button container | `padding-top: 32px` | When button is below text |
| Divider | `32px 0` | Vertical breathing room |
| Social icons | `16px` | Around each icon |
| List items | `margin: 8px 0` | Comfortable reading |

### Vertical Rhythm

- Between paragraphs: `24px` (margin-bottom on paragraphs)
- Between heading and content: `24px`
- List margin: `24px top/bottom`
- Minimum section gap: `32px`

## Implementation Notes

### Achieving the Floating Effect

1. Set both `<body>` and main container `background-color` to `#fcfcfc`
2. Remove border-radius from container edges (no rounded email corners)
3. Apply `border-radius: 16px` to individual content cards
4. Use `#f1f0f0` for card backgrounds
5. Add 24px gap between floating cards

### Outlook Considerations

- VML fallbacks not required for pill buttons (border-radius degrades gracefully)
- Use `bgcolor` attribute alongside `background-color` style for Outlook
- Test rounded corners in Outlook 2016+ (partial support)

### Mobile Responsiveness

```css
@media only screen and (max-width:480px) {
  /* Stack columns */
  .mj-column-per-50 { width: 100% !important; max-width: 100% !important; }

  /* Adjust padding for mobile */
  .mobile-padding { padding: 24px 24px !important; }

  /* Full-width buttons on mobile */
  .mobile-button { width: 100% !important; }
}
```
