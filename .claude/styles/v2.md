# Style Guide v2

**Version:** 2.2
**Based on:** Modern minimal aesthetic with floating elements + original brand colors
**Last Updated:** January 2026

---

## Overview

v2 is a modern, minimal design system focused on clarity, breathing room, and a light, airy feel. The design prioritizes readability and a premium aesthetic while maintaining the original ITRG brand blue.

**Design Principles:**

1. **Floating Elements** - Cards float on a clean white background with generous spacing between them
2. **Light & Airy** - Subtle greys, lighter typography weights, and ample whitespace
3. **Brand Blue Accent** - ITRG blue (#216aa5) for CTAs and interactive elements
4. **Refined Typography** - Smaller, lighter body copy with full type scale from v1
5. **Generous Rhythm** - Consistent vertical spacing creates visual calm

## Key Design Decisions

| Element | v1 | v2 | Rationale |
|---------|----------|---------|-----------|
| Body/Container background | `#ededed` | `#ffffff` | Cleaner, lighter base |
| Card background | `#f6f6f6` | `#f7f7f7` | Subtler contrast, more refined |
| Primary accent | `#24842e` (green) | `#216aa5` (blue) | Unified brand color |
| Body text color | `#000000` | `#374151` | Softer, easier to read |
| Body text size | `16px` | `15px` | More refined, less chunky |
| Body text weight | `400` | `300` | Lighter, more elegant |
| Module spacing | `24px` | `16px` | Consistent gap between all modules |
| Card border-radius | `20px` | `20px` | Maintained soft corners |
| Button border-radius | `5px` | `50px` | Full pill shape |

## Spacing System

### Base Unit

The spacing system uses an **8px base** with a focus on generous whitespace.

| Token | Value | Usage |
|-------|-------|-------|
| `xs` | 8px | Tight spacing, inline elements |
| `sm` | 12px | Small gaps |
| `md` | 16px | **Module gaps**, standard spacing |
| `lg` | 24px | Section padding, heading margins |
| `xl` | 32px | Large sections |
| `2xl` | 48px | Body padding, major sections |
| `3xl` | 64px | Hero sections |

### Module Spacing (Critical)

**Every module has 16px margin-bottom** to create consistent vertical rhythm:

```
┌─────────────────┐
│    Module A     │
└─────────────────┘
        ↕ 16px
┌─────────────────┐
│    Module B     │
└─────────────────┘
        ↕ 16px
┌─────────────────┐
│    Module C     │
└─────────────────┘
```

### Container Spacing

| Element | Padding | Notes |
|---------|---------|-------|
| Body | `48px 0` | Top/bottom breathing room |
| Card module | `36px 40px` | Generous interior |
| Small card | `28px 32px` | Two-column cards |
| Header | `24px 40px` | Lighter than content |
| Footer | `40px 40px` | Balanced |

- `button-primary` - ITRG blue pill button

- `spacer-lg` - 24px space
