## Brand Variants

This template supports three brand variants:

| Brand | Abbreviation | Primary Color | Usage |
|-------|--------------|---------------|-------|
| SoftwareReviews | SR | `#24842e` (Green) | Default brand |
| Info-Tech Research Group | ITRG | `#216aa5` (Blue) | Secondary brand |
| Advisory | Advisory | Uses both logos | Combined branding |

### Brand Selection Rules

- Use SR (green) modules when the email is primarily SoftwareReviews branded
- Use ITRG (blue) modules when the email is primarily Info-Tech branded
- Use Advisory header for marketing/advisory content
- Modules with `--SR` suffix use green styling
- Modules with `--ITRG` suffix use blue styling

## Spacing System

### Base Unit

The spacing system is based on multiples of **8px** with some exceptions.

### Container Spacing

| Element | Padding | Notes |
|---------|---------|-------|
| Body | `24px 0` | Top/bottom only |
| Standard module | `24px 47px` | Left/right consistent |
| Grey section module | `24px 52px` | Slightly wider for cards |
| Full-width image | `0` | Edge-to-edge |
| Header | `23px 47px` top/bottom | Slightly less than standard |
| Footer top | `48px 47px` | More breathing room |
| Footer bottom | `0 47px 36px` | Social icons section |

### Inner Column Spacing

| Element | Padding | Notes |
|---------|---------|-------|
| Column wrapper | `0 5px` | Gutter between columns |
| Text alignment cell | `10px 0` or `10px 34px 10px 0` | Header elements |

### Section Inner Padding

| Element | Padding | Notes |
|---------|---------|-------|
| Grey card (large) | `40px` | Main grey sections |
| Grey card (small) | `20px` | Two-column grey cards |
| Number step icon | `0 0 24px 0` | Below step numbers |

### Component Spacing

| Element | Padding/Margin | Notes |
|---------|----------------|-------|
| Button | `12px 22px` | Internal padding |
| Button container | `padding-top: 32px` | When button is below text |
| Divider | `24px 47px` | Module padding includes divider |
| Social icons | `12px` | Around each icon |

### Vertical Rhythm

Standard vertical spacing between elements:

- Between modules: 24px (built into module padding)
- Between heading and content: 24px (margin-bottom on headings)
- Between paragraphs: 0 (no margin, use modules for spacing)
- List margin: 16px top/bottom
